# 三维评分量表与入选分诊

三个维度**独立打分，不得合成总分**（硬约束 7）。每条研究在简报中必须显示 `S/N/R` 三个数字。

---

## 维度 1：Evidence strength（证据强度）1–5

先做**表型归一化**再打分：标注人群（儿童 / 成人 / 混合）与疾病定义（活检确诊 MCD / SSNS 临床表型 / 含 FSGS / 未分层）。

| 分 | 锚点 |
|---|---|
| 5 | 儿童人群的随机对照试验，或纳入儿童 RCT 的系统综述/Meta 分析；或主要指南的正式更新 |
| 4 | 儿童多中心前瞻队列；或成人 RCT + 明确的儿童适用性论证；或高质量单中心 RCT（样本偏小） |
| 3 | 儿童前瞻队列 / 大样本注册研究 / 设计良好的回顾队列（有对照） |
| 2 | 回顾性病例系列（无对照）、横断面、小样本探索性研究 |
| 1 | 动物模型、类器官、体外、纯组学、个案报告、会议摘要 |

**降级规则**（各扣 1 分，可叠加，下限 1）：
- 混合成人/儿童人群且未分层报告
- 混合 MCD/FSGS 且未分层报告
- 仅为预印本或未同行评议（Europe PMC `SRC:PPR` 条目一律适用）
- 主要终点为替代指标（如仅蛋白尿变化，无复发/缓解终点）

---

## 维度 2：Novelty（新颖度）1–3

**相对 `state.baseline` 判断，不是相对文献总体。**

| 分 | 锚点 |
|---|---|
| 3 | 推翻、改写或显著限定既有基线结论；或首次出现的机制/靶点/指南立场 |
| 2 | 在既有方向上提供新的量化、新的亚组、新的比较臂或新的安全信号 |
| 1 | 重复既有结论的确证性证据（仍可入附录，不进正文的「新发现」段） |

非索引来源的指南/共识更新（KDIGO / IPNA / ESPN）命中即计 3。

---

## 维度 3：Patient relevance（患者相关性）1–3 或 N/A

需要 `patient-profile.md`。文件不存在时**全部标记 `N/A`**，简报中该列留空并在抬头说明。

| 分 | 锚点 |
|---|---|
| 3 | 直接匹配当前表型 + 当前或近期考虑中的用药/决策点 |
| 2 | 匹配表型但涉及尚未考虑的方案；或匹配当前用药的长期安全性 |
| 1 | 同疾病谱但表型/年龄段/治疗线不匹配 |

---

## 入选分诊

| 判定 | 条件 |
|---|---|
| **进正文（material）** | `S ≥ 3 且 N ≥ 2`，**或** `R = 3`（任意 S/N），**或** 走阴性结果通道 |
| **进附录清单（appendix）** | 其余全部命中条目，只列标题 / PMID / 一行摘要 |
| **丢弃** | 仅当明显跑题（疾病或领域不符）；不因「结论不利」或「样本小」丢弃 |

正文条目上限建议 12 条；超出时按 `R` 降序、再按 `S` 降序截断，被截断的降入附录并注明「因篇幅降级」。

### 阴性结果豁免通道

阴性 / 无效 / 非劣效未达成的结果天然 `N` 低，但对**停药、减毒、避免过度治疗**决策价值极高，最容易被规则误杀。

> 满足 `S ≥ 3` 的阴性或无效结果**直接进正文**，不受 `N ≥ 2` 限制，并在条目上标注 `[阴性结果]`。

同样处理：安全性信号（新的不良事件、剂量相关毒性）满足 `S ≥ 2` 即进正文，标注 `[安全信号]`。

### 预印本上限

预印本经降级后 `S` 上限为 2，因此**永远不会**单独满足 `S ≥ 3` 而进正文的通道；
它们只在 `R = 3` 时进正文，否则归入独立的「预印本（未同行评议）」小节。
预印本不得写入 `state.baseline`——基线只接受同行评议后的证据。

## 打分自检

写入简报前逐条检查：

- [ ] 是否已标注人群年龄段与疾病表型？（先于打分）
- [ ] SSNS 是否被当成活检确诊 MCD？（硬约束 1）
- [ ] 成人证据是否带了显式适用性标签？（硬约束 2）
- [ ] 机制证据是否被表述成了临床疗效？（硬约束 3）
- [ ] 是否出现了「导致 / 证明有效」这类因果表述而研究是观察性的？（硬约束 4）
- [ ] 单项研究是否在未论证的情况下推翻了基线？（硬约束 5）
- [ ] `what_this_changes` 与 `what_this_does_not_prove` 是否都非空且非套话？（硬约束 6）
- [ ] 生物标志物是否混用了诊断/预后/预测三种功能？
